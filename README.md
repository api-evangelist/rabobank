# Rabobank (rabobank)

Rabobank is a Dutch multinational banking and financial services company organized as a cooperative with a strong focus on the food and agriculture sector. It serves retail, business, corporate, and wholesale customers in the Netherlands and operates a global Food & Agribusiness practice. Rabobank publishes a developer portal at docs.developer.rabobank.com (legacy developer.rabobank.nl redirects there) exposing PSD2-mandated open banking APIs (Account Information, Payment Initiation, Funds Confirmation) plus Premium/Beyond-PSD2 commercial APIs for corporate cash management and real-time notifications. Underlying schemes are aligned with the Berlin Group NextGenPSD2 XS2A Framework.

## APIs

| API | Description |
|---|---|
| Rabobank Account Information API (PSD2 AIS) | PSD2 AIS - balances and transactions after account-holder consent (Berlin Group XS2A). |
| Rabobank Payment Initiation API (PSD2 PIS) | PSD2 PIS - initiate SEPA / SEPA Instant / cross-border payments after SCA. |
| Rabobank Funds Confirmation API (PSD2 PIIS / CBPII) | PSD2 PIIS - confirm sufficient funds for a card-based payment. |
| Rabobank Premium Payments / SEPA Credit Transfer API | Commercial corporate cash-management SEPA initiation without per-payment SCA. |
| Rabobank Notifications API | Event notification / webhook delivery for payment, account, and consent state changes. |
